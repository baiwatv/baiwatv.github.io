# 防丢失发布页

一个纯静态的「官方发布页」：用户收藏这一个网址，主站域名变了也能在这里找到最新地址。

## 域名变了怎么改（手动更新，1 分钟搞定）

1. 打开本仓库的 `index.html`，点右上角铅笔图标（Edit）
2. 找到文件开头 `CONFIG` 里的 `domains` 部分：

   ```js
   domains: [
     "https://example1.com",
     "https://example2.com",
   ],
   ```

3. 改成新域名（一行一个，每行末尾保留逗号），顺手把下面的 `updated` 改成当天日期
4. 点绿色的 **Commit changes** 按钮

保存后 1~2 分钟，发布页自动更新，用户刷新即可看到新域名。

## 注意

- 只需要改 `CONFIG` 那一段，页面其他部分不用动
- 网址要带 `https://` 开头
- TG 频道/群链接同理，在 `telegram` 部分改
